## Context captured at init
- DryHack-MCP: an MCP server (Python, FastMCP) exposing offensive-security tools
  (`curl`, `python`, `shell`, `recommend_action`) for authorized pentesting.
- Installable via `python3 -m pip install .`; console script `dryhack-mcp`.
- Two transports selectable via argparse: stdio (default) and http (streamable
  HTTP, served at `/mcp`).
- `recommend_action` consults an OpenAI-compatible "safeguard API" with an
  optional "unrestricted" framing mode and an offline heuristic fallback.
- Configuration entirely via `DRYHACK_*` environment variables; no database.
- Current version 0.1.0.
